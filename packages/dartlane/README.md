# dartlane

The Dartlane command line: init, run, list, doctor and update.

Part of [Dartlane](https://github.com/AbhijithKonnayil/dartlane): lanes and actions for Flutter release automation, written in Dart. Dartlane is early. Today it builds Android APKs and app bundles and uploads them to Firebase App Distribution.

See the [quick start](https://github.com/AbhijithKonnayil/dartlane/blob/dev/docs/quick-start.md).
