# Dartlane

<p align="center">
  <img src="assets/dartlane.png" width="300" alt="dartlane logo" />
</p>

A Dart-powered CLI tool to define, manage, and run tasks (lanes) with speed and flexibility, inspired by Fastlane.

## Installation

```sh
dart pub global activate dartlane
```

## Usage

Define your lanes in `dartlane/lanes.dart` within your project.

```sh
# Run a specific lane
dartlane run [lane_name]

# List available lanes
dartlane --help
```
